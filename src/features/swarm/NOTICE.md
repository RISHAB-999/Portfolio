# Swarm (Motion) — credits

The Motion effect in this folder is inspired by:

- **Swarmline** by imperfec-t — https://github.com/imperfec-t/swarmline (MIT for Swarmline's own code)
- **Swarm Rebuild** by Dhvanil Patel — https://github.com/DhvanilPatel/swarm-cursors
- **Swarm** by Joel Califa — https://califa.github.io/swarm-site/

Swarmline's license states that the parts of its engine adapted from Swarm Rebuild and
Swarm (cursor motion, the boids orbit, the build gestures, the drawing layer) are used
with those authors' permission and remain theirs, so they are not covered by the MIT
grant. For that reason no code was copied from any of these projects: `swarmEngine.js`,
`scanPage.js` and `deviceProfile.js` are an independent implementation written for this
portfolio, following the same idea (a crew of cursors visibly rebuilding the page).

The cursor names, colours, selection colour (the portfolio's cyan) and all code here are
this portfolio's own.

## Loading-screen coffee cup

`coffeeLoader.js` is a canvas/pixel-art port of a CSS "coffee cup" loader from
CodePen that the site owner supplied (geometry, keyframes and easing follow the
original CSS). Public CodePen pens are MIT licensed; if the pen's author is
known, add their name and the pen URL here.
